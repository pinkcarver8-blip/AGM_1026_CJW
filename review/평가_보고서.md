# 랜딩페이지 반복 개선 보고서

대상: `care-hero-landing-gangdong.html` (우리동네 돌봄 히어로 · 강동구 선생님 모집)
방법: Playwright(Chromium)로 7개 해상도를 전체 페이지 캡처하고, 같은 스크립트로 가로 넘침·작은 글자·터치 영역·CTA 위치·혜택 문구를 측정했습니다. 점수는 이 측정값과 캡처를 직접 보고 매긴 자체 평가입니다.

해상도: 폴더블 커버 280 · 스마트폰 360 · 412 · 폴더블 펼침 720 · 태블릿 820 · 데스크탑 1440 · 와이드 1920

## 회차별 개선 내용

### 1회차 (56점) — 처음 상태
- 280px에서 헤더 버튼이 두 줄로 깨지고 제목이 글자 중간에서 끊김
- 하단 고정 버튼이 히어로 버튼을 가림
- 혜택이 상단과 하단에 없고, "활동 경력 관리"는 FAQ에서도 빠짐
- 카드 아이콘이 범용이고, 추천 보상 아이콘이 슬픈 얼굴처럼 보임
- 데스크탑 요약 바가 두 배경색에 걸쳐 어색함, 메뉴 터치 영역 26px
- 캡처: `iter-1/board.png`

### 2회차 (80점) — 구조 개편
- **혜택 일관성:** 4가지 이름과 아이콘을 하나로 통일해 상단 칩, 혜택 카드, FAQ 태그, 하단 요약에 같은 그림으로 반복
- **이미지:** 혜택마다 장면 일러스트 추가 (달력→동전, 대화 말풍선+방패, 프로필 카드 예시, 선물 전달). 지도에도 "첫 활동 지원" 스티커 추가
- **CTA:** 혜택 섹션 직후 CTA 띠, 시작 방법 1단계 버튼, 헤더 버튼 추가. 하단 고정 버튼은 히어로와 다운로드 구간에서 숨김
- **해상도:** 제목 단어 단위 줄바꿈, 280px 전용 규칙, 640px 이하 1열, 요약 바를 히어로 안으로 이동
- 캡처: `iter-2/board.png`, `iter-2/perks-desktop.png`

### 3회차 (87점) — 일러스트 결함 수정
- 활동 경력 관리: 알약이 값을 가리고 딱지가 카드 밖으로 나가던 것을 카드 안 3행으로 재배치
- 추천 보상: 잘리던 "나", "이웃" 글자를 위로 올리고 "추천한 나"로 명확히
- 지도의 "어린이집" 글자를 건물 옆으로, 혜택 스티커를 나무와 겹치지 않는 곳으로 이동
- 13px 글자를 14px로
- 캡처: `iter-3/board.png`, `iter-3/perks-desktop.png`, `iter-3/perks-phone360.png`, `iter-3/hero-desktop.png`

### 4회차 (90점) — 마무리
- 280px 로고 터치 영역 보강 → 7개 해상도 모두 가로 넘침 0, 14px 미만 글자 0, 40px 미만 터치 영역 0
- 스크롤 위치별 점검: 모바일은 모든 구간에서 CTA 1개 이상 보이고 히어로·다운로드 구간에서 고정 버튼이 중복되지 않음. 데스크탑은 헤더 버튼이 항상 보임
- 캡처: `iter-4/board.png`, `iter-4/perks-fold-cover-280.png`, `iter-4/perks-fold-open-720.png`

## 남은 한계 (솔직하게)
- **280px 일러스트 글자가 작습니다.** 그림 속 글자가 약 11px로 줄어듭니다. 카드 제목과 본문에 같은 내용이 있어 정보 손실은 없지만, 읽기 편하진 않습니다. 해상도 항목이 12/15에 머문 이유입니다.
- **실제 기기 검증이 아닙니다.** 화면 크기와 터치를 에뮬레이션한 것이고, 실제 갤럭시 Z 폴드/플립 접힘 상태 전환은 못 봤습니다.
- **스토어 링크는 비어 있습니다** (`TODO` 주석 위치). 연결 전까지 다운로드 버튼은 동작하지 않습니다.
- **프로필 일러스트의 ○○는 예시 표기**입니다. 실제 앱 화면이 아니며 "프로필 예시" 딱지가 붙어 있습니다.

## 5회차 — 일러스트 전면 교체
- 기존 일러스트(굵은 윤곽선의 도형 지도, 범용 아이콘, 이모지)를 모두 삭제하고 면 중심의 플랫 스타일로 다시 그림
- 히어로: 아파트 단지와 어린이집이 있는 강동구 동네 거리에서, 히어로 망토를 두른 선생님이 아이와 손잡고 걷는 장면
- 혜택 장면 4개를 같은 인물 세트로 새로 그림: 달력+봉투+동전 / 보호자·운영팀 대화 / 프로필 화면 예시 / 추천 → 교육 수료 → 선물
- 혜택 아이콘 4개, 하는 일 아이콘 3개도 같은 스타일로 교체
- 교체 후에도 7개 해상도 모두 가로 넘침 0, 14px 미만 글자 0, 작은 터치 영역 0, 혜택 4가지 일관성 유지
- 이전 일러스트 버전: `review/랜딩페이지(조영흠).v4-이전일러스트.html`
- 캡처: `review/illus-1`, `review/illus-2`
